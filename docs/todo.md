# Улучшения общие

## Поддержать ENUM-ы

Необходимо поддержать ENUM типы постгреса и дать возможность их описывать в полях и генерировать константы

## Сделать возможность отключать определённые методы

Логически не во все таблицы должны быть доступны все методы работы с ней. Например есть таблицы в которые производиться только запись и выборка, нет апдейтов и удалений. Надо сделать возможно отключать генерацию определённых методов, что бы не давать возможности разработчикам наступить на грабли.

## RO поля

Сделать возможность помечать поля признаком ReadOnly для случаев, когда поля обновляются хранимкой и из них можно в коде только читать. В этом случае не генерируем Set метод.

## Первичный ключ (primary_key)

Проверять что описан один и только один первичный ключ

## Отсутствие доступа в view

При отсутствии доступа к view возвращается пустой результат без ошибки и отличае от отсутствия доступа к таблице. Проблема в драйвере pgx. Было бы неплохо найти и расковырять проблему.
